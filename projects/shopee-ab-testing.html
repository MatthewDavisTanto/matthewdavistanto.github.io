UX / USER RESEARCH

Shopee Cart Navigation A/B Testing

Exploring alternative cart navigation interfaces to improve product discovery and navigation for users managing multiple products.

Project Overview

This project explored a proposed navigation improvement for the Shopee Cart. The feature focused on helping users manage and navigate larger numbers of products more efficiently.

Project Type Academic UX Project
Focus UX Research & A/B Testing
Tool Figma

The Problem

The project began from research and survey findings suggesting that users could benefit from additional sorting and filtering options when managing products in the Shopee Cart.

The proposed feature focused on:

  • Sort By
  • Filter
  • Calendar-based navigation
  • Search
DESIGN EXPLORATION

Design A vs Design B

Two alternative navigation approaches were explored to determine which interface better supported efficient cart navigation.

DESIGN A

Compact navigation

3111 × 1034 px

Design A grouped the main navigation controls at the top of the cart interface. Sort By, Calendar, and Filter were accessed through additional interface states.

DESIGN B

Direct navigation

3111 × 1489 px

Design B exposed more sorting options directly within the cart interface and used clearer text-based navigation for filtering and date selection.

A/B TESTING

User preference.

Both designs were presented to seven participating groups to compare overall preference and collect qualitative feedback.

Design A 3 of 7 responses
42.8%
Design B 4 of 7 responses
57.2%
KEY TAKEAWAY Design B led by 14.4 percentage points.

Design B received the majority preference, with participants highlighting direct sorting access, clearer filter labels, and a more familiar calendar interaction.

User Feedback

Design B was generally preferred for its efficiency, clearer text-based filtering, reduced reliance on pop-ups, and more familiar calendar interaction.

Design A was preferred by some participants because it appeared cleaner, simpler, and more visually compact.

Result & Insight

Design B received the majority of preferences with 57.2% of responses.

The findings suggest that direct access to sorting and clearer filter labels may improve perceived efficiency when navigating a cart containing many products.

What I Learned

  • How to translate user feedback into interface requirements.
  • How to compare alternative interface solutions through A/B testing.
  • How qualitative feedback can complement quantitative preference results.
